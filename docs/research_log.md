## Evidence labels
- **VERIFIED:** independently rerun and confirmed.
- **MEASURED:** output captured from a real run with configuration and provenance.
- **PROVISIONAL:** preliminary result requiring confirmation.
- **PLANNED:** not yet implemented or measured.
- **ILLUSTRATIVE:** synthetic/local demonstration; never present as benchmark evidence.
